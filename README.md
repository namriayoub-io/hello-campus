# Hello Campus 📱

## Présentation

Hello Campus est une première application mobile réalisée avec React Native, Expo et TypeScript dans le cadre du TP de développement mobile (IAIL S5).

## Fonctionnalités

* Affichage du message « Bonjour Campus ! »
* Affichage de la filière « IAIL S5 - Developpement mobile »
* Bouton « Bienvenue » qui affiche un message de confirmation.

## Technologies utilisées

* React Native
* Expo
* TypeScript

## Auteur

**Ayoub Namri**

## Objectif

Découvrir les bases du développement mobile, la création d’une interface utilisateur et la gestion des interactions avec `Pressable` et `Alert`.

## Lancement du projet

```bash
npm install
npx expo start
```
